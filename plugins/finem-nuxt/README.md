# Finem Nuxt

Nuxt 4 server rendering and Pinia state

**Claude Code**

```bash
claude plugin install finem-nuxt@finem
```

**Codex**

```bash
codex plugin add finem-core@finem
codex plugin add finem-vue@finem
codex plugin add finem-nuxt@finem
```

**Depends on** `finem-core`, `finem-vue`. Claude Code installs those automatically; Codex does not resolve dependencies, so the Codex commands above install them in order.
