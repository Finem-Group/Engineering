# Finem Backend rust

Rust ownership, errors, testing and performance conventions

**Claude Code**

```bash
claude plugin install finem-backend-rust@finem
```

**Codex**

```bash
codex plugin add finem-core@finem
codex plugin add finem-backend-rust@finem
```

**Depends on** `finem-core`. Claude Code installs those automatically; Codex does not resolve dependencies, so the Codex commands above install them in order.

| Capability | Role | Originals |
| --- | --- | --- |
| Backend | adds to base | 1 |
| Reliability/resilience | adds to base | 1 |
| Testing | adds to base | 1 |

Native skills: 1. Bundled originals: 1 from 1 source repository (apollo), unmodified under `upstream/`. See `NOTICE.md` for licenses and pinned revisions.
