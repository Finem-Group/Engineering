# Finem Product analytics

Metrics definitions and cohort-based feedback alongside provider instrumentation

**Claude Code**

```bash
claude plugin install finem-product-analytics@finem
```

**Codex**

```bash
codex plugin add finem-core@finem
codex plugin add finem-product-analytics@finem
```

**Depends on** `finem-core`. Claude Code installs those automatically; Codex does not resolve dependencies, so the Codex commands above install them in order.
