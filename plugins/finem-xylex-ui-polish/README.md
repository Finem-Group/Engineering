# Finem Xylex ui polish

Original XYLEX web component polish, CSS transition recipes and website token extraction

**Claude Code**

```bash
claude plugin install finem-xylex-ui-polish@finem
```

**Codex**

```bash
codex plugin add finem-core@finem
codex plugin add finem-xylex-ui-polish@finem
```

**Depends on** `finem-core`. Claude Code installs those automatically; Codex does not resolve dependencies, so the Codex commands above install them in order.
