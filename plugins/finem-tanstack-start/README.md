# Finem Tanstack start

TanStack Start React full-stack rendering

**Claude Code**

```bash
claude plugin install finem-tanstack-start@finem
```

**Codex**

```bash
codex plugin add finem-core@finem
codex plugin add finem-tanstack-router@finem
codex plugin add finem-tanstack-start@finem
```

**Depends on** `finem-core`, `finem-tanstack-router`. Claude Code installs those automatically; Codex does not resolve dependencies, so the Codex commands above install them in order.
