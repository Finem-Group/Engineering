# Finem Aws containers

AWS container selection and infrastructure deployment guidance

**Claude Code**

```bash
claude plugin install finem-aws-containers@finem
```

**Codex**

```bash
codex plugin add finem-core@finem
codex plugin add finem-aws-containers@finem
```

**Depends on** `finem-core`. Claude Code installs those automatically; Codex does not resolve dependencies, so the Codex commands above install them in order.
