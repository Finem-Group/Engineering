# Finem Backend apollo

Apollo Server context, resolvers, authorization and operations

**Claude Code**

```bash
claude plugin install finem-backend-apollo@finem
```

**Codex**

```bash
codex plugin add finem-core@finem
codex plugin add finem-api-graphql@finem
codex plugin add finem-backend-apollo@finem
```

**Depends on** `finem-core`, `finem-api-graphql`. Claude Code installs those automatically; Codex does not resolve dependencies, so the Codex commands above install them in order.
