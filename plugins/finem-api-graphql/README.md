# Finem Api graphql

GraphQL schema and operation contracts independent of server provider

**Claude Code**

```bash
claude plugin install finem-api-graphql@finem
```

**Codex**

```bash
codex plugin add finem-core@finem
codex plugin add finem-api-graphql@finem
```

**Depends on** `finem-core`. Claude Code installs those automatically; Codex does not resolve dependencies, so the Codex commands above install them in order.

| Capability | Role | Originals |
| --- | --- | --- |
| API contracts | base | 2 |
