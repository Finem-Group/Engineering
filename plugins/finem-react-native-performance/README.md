# Finem React native performance

Measure and optimize native JS, bundle and device performance

**Claude Code**

```bash
claude plugin install finem-react-native-performance@finem
```

**Codex**

```bash
codex plugin add finem-core@finem
codex plugin add finem-react-native-performance@finem
```

**Depends on** `finem-core`. Claude Code installs those automatically; Codex does not resolve dependencies, so the Codex commands above install them in order.

| --- | --- | --- |
| Performance | base | 1 |
