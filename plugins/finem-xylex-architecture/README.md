# Finem Xylex architecture

Original XYLEX module design and domain modeling specialists

**Claude Code**

```bash
claude plugin install finem-xylex-architecture@finem
```

**Codex**

```bash
codex plugin add finem-core@finem
codex plugin add finem-xylex-architecture@finem
```

**Depends on** `finem-core`. Claude Code installs those automatically; Codex does not resolve dependencies, so the Codex commands above install them in order.
