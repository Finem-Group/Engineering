# Finem Backend hono

Hono API implementation for a selected project runtime

**Claude Code**

```bash
claude plugin install finem-backend-hono@finem
```

**Codex**

```bash
codex plugin add finem-core@finem
codex plugin add finem-backend-hono@finem
```

**Depends on** `finem-core`. Claude Code installs those automatically; Codex does not resolve dependencies, so the Codex commands above install them in order.
