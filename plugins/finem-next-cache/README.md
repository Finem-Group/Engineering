# Finem Next cache

Next 16.3+ instant-navigation tests for apps already building with Cache Components

**Claude Code**

```bash
claude plugin install finem-next-cache@finem
```

**Codex**

```bash
codex plugin add finem-core@finem
codex plugin add finem-browser-playwright@finem
codex plugin add finem-next-cache@finem
```

**Depends on** `finem-core`, `finem-browser-playwright`. Claude Code installs those automatically; Codex does not resolve dependencies, so the Codex commands above install them in order.
