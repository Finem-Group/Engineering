# Migrating the 0.6 lifecycle plugins

Version 0.7 organizes the stack by recognizable engineering disciplines: UI/UX, Infrastructure & DevOps, Security & Privacy and the other areas listed in [engineering disciplines and direction](area-plugins.md).

The seven 0.6 phase selectors remain compatibility aliases after installing the new area plugins. Their capability scope is preserved. The [complete migration map](plugin-migration.json) lists replacement areas and retained capability IDs. Existing CLI profiles and extension selections remain unchanged.
